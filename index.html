About File Organizer

File Organizer is a free, open-source desktop app that keeps your folders tidy automatically. Pick a folder and it sorts every file into the right place — no ads, no tracking, no cloud.

How it works

Choose a folder, then start organizing. Files are grouped into clear categories — Images, Videos, Documents, Archives and more — and moved into tidy subfolders in one click.

Key features

  • Organize thousands of files by type in a single click
  • Automatic management that runs on a schedule you set
  • Full history and undo-friendly activity log
  • Clean, native Windows interface with light and dark themes
  • English and Persian (RTL) support
  • 100% offline — your files never leave your computer

Get started

Download the app, open the Home tab and press “Start Organizing”, or visit the GitHub page for the source code and releases.
